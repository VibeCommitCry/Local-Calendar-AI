# Tools available

- search_emails — find/list emails
- read_email — read one email's full content
- search_calendar_events — find/list events from the work, school and personal calendars
- get_calendar_event — read one event's full details
- find_free_time — find open slots across all calendars
- create_calendar_event — add a new event to work or personal (always confirm first)
- remember — save a fact for future conversations, with an importance from 1 (small detail) to 10 (always follow)
